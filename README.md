# Автоматизированные UI‑тесты для веб‑приложений

Проект содержит набор автоматизированных UI‑тестов для веб‑приложений, реализованных с использованием Python, Selenium WebDriver, PyTest и Allure.

## Структура проекта
# HW_Python
    ├── 10_lesson/
    │    │
    │    ├── pages/   # Папки с классами Page Object для разных страниц приложения
    │    │    │
    │    │    ├── AuthorizationPage.py           # Страница авторизации
    │    │    ├── CalculatorPage.py              # Калькулятор с задержкой
    │    │    ├── CartPage.py                    # Страница корзины
    │    │    ├── InformationPage.py             # Страница информации для оформления заказа
    │    │    ├── OverviewPage.py                # Страница обзора заказа
    │    │    └── ProductsPage.py                # Страница товаров
    │    │
    │    ├── Allure-Slow-Calculator_auto_test.py # Тест калькулятора с задержкой
    │    └── Allure-Swag-Labs_auto_test.py       # Тест процесса покупки в интернет‑магазине
    │
    ├── README.md # Эта документация
    └── requirements.txt # Список зависимостей проекта

## Предварительные требования

Перед запуском тестов убедитесь, что у вас установлены:

* Python версии 3.8 или выше.
* Менеджер пакетов `pip`.
* Веб‑браузеры:
  * Google Chrome (для теста калькулятора);
  * Mozilla Firefox (для теста интернет‑магазина).
